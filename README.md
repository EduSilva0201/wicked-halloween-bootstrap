# WICKED — Halloween

Projeto acadêmico de desenvolvimento web do segundo semestre de 2026. A página reúne conteúdo sobre Halloween, cinema, livros e folclore para praticar a construção de interfaces com Bootstrap.

## Tecnologias

HTML5, CSS3, Bootstrap (CSS e JavaScript) e Font Awesome. As dependências usadas pela página estão incluídas no repositório.

## Componentes praticados

- Navbar responsiva e menu suspenso.
- Carrossel de imagens e cards.
- Acordeão de curiosidades.
- Painel lateral (offcanvas), modal e spinner demonstrativo.

## Como executar

1. Clone o repositório:

```bash
git clone https://github.com/EduSilva0201/wicked-halloween-bootstrap.git
cd wicked-halloween-bootstrap
```

2. Abra `index.html` no navegador. Não é necessário instalar dependências nem configurar banco de dados.

Como alternativa, com Python instalado, execute `python -m http.server 8000` e acesse http://localhost:8000.

## Estrutura

- `index.html`: conteúdo e componentes da página.
- `css/`: estilos do Bootstrap.
- `js/`: JavaScript do Bootstrap com Popper.
- `fontawesome/`: estilos e fontes dos ícones.
- `img/`: imagens utilizadas na atividade.

## Limitações

Este é um exercício de frontend, sem backend. O campo de busca não realiza pesquisas; os links com `#` e alguns botões são demonstrativos. O spinner é uma demonstração visual, sem carregamento associado. O código original da atividade foi preservado.
